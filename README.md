# MARKENS JARVIS

Голосовой помощник Windows с локальным словом активации «Джарвис», плавающей панелью, Gemini Live, памятью и ограниченным управлением компьютером.

## Установка

Скачайте единый установщик **JARVIS-SETUP.cmd** из сообщения ChatGPT и запустите двойным щелчком. Установщик подготовит Python, виртуальное окружение, зависимости и ярлыки. Исходники вручную распаковывать не нужно.

## Обновления

Установленная версия проверяет этот репозиторий через `latest.json`. Проверка выполняется при запуске и периодически во время работы. Новая версия должна быть опубликована как ZIP по адресу из манифеста и сопровождаться SHA-256. Приложение проверяет контрольную сумму перед применением обновления и сохраняет предыдущую версию для отката при неудачном запуске.

## Приватность и безопасность

- Слово активации распознаётся локально.
- Аудио не отправляется в Gemini до активации.
- Доступ к файлам и действиям Windows ограничен набором разрешённых инструментов.
- Опасные действия требуют подтверждения.
- Не отправляйте в облачную модель пароли и другую конфиденциальную информацию.
